# F1 research figures

The page displays five original notebook exports: `downforce.png`, `grip.png`, `tradeoff.png`, `drag-penalty.png`, and `flow-field.png`. The notebook `Final-Project.ipynb` is retained as research provenance. Existing bilingual descriptions explain the sampled lap-time proxy and the limitations of the unvalidated CFD prototype.

Unused generated SVG figures and the undisplayed `longitudinal.png` / `circuits.png` were archived outside the website during cleanup on 2026-11-10.

`tools/render_f1_plots.py` and `tests/f1-model.test.py` remain useful for checking the analytical model. Running the renderer optionally regenerates four SVG figures; they are not required by the current website.
